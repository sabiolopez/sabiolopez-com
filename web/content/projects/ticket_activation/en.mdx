description: "Reorganizing Ticket Portal onboarding to make activation paths clearer and facilitate placing the first order."
context: |
  In the Ticket Portal, the first order marks the activation of a new contract. Until reaching that point, clients may need to register employees, upload files, or configure products. This preparation involves different paths and returns to the portal that were not always clear in the user experience.

  In partnership with the PO, I participated in discovery and led the design process to make these paths more visible and reduce friction up to the first order. I also built dashboards and performed data analysis. The proposal reorganized the home page to guide the client's operations, giving direct access to existing features and tracking behavior by profile and entry path.

problemSection:
  title: "Unclear Activation Paths"
  description: "The funnel revealed drop-offs between contract signing and the first order. Dispersed actions and mandatory steps hindered progress across different activation paths."
  problems:
    - title: "Dispersed Actions"
      description: "Employee registration, file uploads, and manual ordering required discovery in different areas of the portal."
    - title: "Mandatory Step"
      description: "Product configuration blocked manual order initiation, even when the client wanted to start directly with ordering."
    - title: "Multi-stage Journey"
      description: "Placing the first order could take around a month, involving operational prep and multiple portal sessions."
darkSection:
  solutionTitle: "A Home Page That Guides Activation"
  solutionDescription: |
    We reorganized the home page to highlight contracted products and activation actions right at portal entry. The new module provided direct access to existing paths. For manual orders, initial product configuration was no longer a prerequisite.
  strategyTitle: "Project Guidelines"
  strategies:
    - title: "Product as Context"
      description: "Use contracted products as the starting point to orient client actions."
    - title: "Higher Visibility Actions"
      description: "Bring employee registration, user management, and file uploads closer to portal entry."
    - title: "Flexible Sequence"
      description: "Allow manual order initiation without requiring upfront product setup."
    - title: "Measurement by Path"
      description: "Differentiate first-time access and recurring users to monitor conversion and completion time."
